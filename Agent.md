# AI Agent Guidelines

- **Sync Documentation:** Always remind the agent to update relevant documentation files when architecture, setup steps, or APIs change.
- **Protect Secrets:** Ensure the agent never commits environment variables, API keys, or security tokens.
- **Clear Context:** Explain the *why* behind your requests to help the agent make better design choices.
- **Iterative Approach:** Break large features into smaller, verifiable steps. Review changes frequently.
- **Immediate Feedback:** Correct the agent quickly if it takes a wrong path.
